# cpp-practice

Small C++ programs I wrote while learning.

## Programs

**calculator.cpp**
A command-line calculator.Supports +, -, *, / and ^, handles divide-by-zero, and rejects invalid input.

**temp_converter.cpp**
A menu-driven converter between Celsius, Fahrenheit and Kelvin, with a check for temperatures below absolute zero.

## How to run

    g++ calculator.cpp -o calculator
    ./calculator

    g++ temp_converter.cpp -o temp_converter
    ./temp_converter

 What I practiced
Functions, switch statements, loops, and input validation.
